# MABP Posts

Painel (PWA) para o dono da MABP Locações aprovar, reprovar e agendar os posts do Instagram.
Só contém o código do app: os dados ficam no repositório privado `instagram-autopost` e o token de acesso fica apenas no aparelho do dono.

A pasta `midia/` é usada pelo robô por poucos minutos para publicar reels e é esvaziada em seguida.
